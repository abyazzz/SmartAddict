========================================
KETERANGAN ENCODING KOLOM GENDER
========================================

Kolom ke-2 (gender) menggunakan encoding numerik:

0 = Perempuan (Female)
1 = Laki-laki (Male)

Contoh penggunaan dalam CSV:
- Baris dengan gender=0 adalah data untuk Perempuan
- Baris dengan gender=1 adalah data untuk Laki-laki
